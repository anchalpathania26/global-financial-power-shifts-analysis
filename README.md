# Global Financial Power Shift Analysis

## Overview
This project analyzes global shifts in financial power using real-world data on
gold reserves, crude oil trade, and cryptocurrency markets.

The analysis focuses on how BRICS nations, the US, and the EU differ in their
financial strategies, especially during periods of economic uncertainty.

---

## Objectives
- Analyze global gold accumulation trends
- Compare BRICS vs US vs EU reserve strategies
- Study Bitcoin trading dominance across fiat currencies
- Examine crude oil trade patterns and geopolitical impacts
- Apply basic forecasting using moving averages

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Key Focus Areas
- Gold accumulation and reserve diversification
- USD dominance vs BRICS financial strategies
- Cryptocurrency trading trends (Bitcoin)
- Commodity market behavior during global shocks
